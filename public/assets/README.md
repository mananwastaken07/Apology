# Assets Folder

Place your personal files here:

## Photos
Put your photos in the `photos/` subfolder:
```
photos/photo1.jpg
photos/photo2.jpg
photos/photo3.jpg
```

Then update `src/config.js` to match your filenames and add captions.

## Music
Place your mp3 file here:
```
our-song.mp3
```

## Final Photo
Place your special photo here:
```
favourite-photo.jpg
```
